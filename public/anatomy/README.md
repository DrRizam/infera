# Muscle images for the Anatomy quiz

Drop one image per muscle in this folder. The **filename must match** the
`image` field in `src/data/muscles.js` exactly (all lowercase, hyphenated,
`.png`). Until a file exists, that muscle's "identify" question shows a
placeholder.

**Image guidance**
- One muscle clearly shown / highlighted, isolated from clutter.
- Consistent style across the set (same view, same rendering).
- No text labels on the image (it's a "name this muscle" question).
- Roughly 4:3 or square; the app scales to fit (`max-height ~256px`).
- If your files are `.jpg` / `.webp` / `.svg` instead of `.png`, tell the
  dev and the extensions in `muscles.js` get switched — don't just rename.
